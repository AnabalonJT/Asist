# Product: HabitTrack

HabitTrack is a habit and sports tracking application. Users log activities via natural language messages to a Telegram bot, which interprets them using an LLM (OpenRouter). A React web dashboard provides data visualization, statistics, and configuration.

## Core Capabilities

- Natural language activity logging through Telegram
- LLM-powered message interpretation (OpenRouter, free model)
- Web dashboard with stats, calendar, streaks, and calorie tracking
- Configurable reminders via Telegram
- Weekly activity summaries
- Goal setting and progress tracking
- JWT-based authentication linking Telegram accounts to web accounts

## Target Users

Individual users who want a low-friction way to track habits and physical activities by simply messaging a Telegram bot, with a visual dashboard for reviewing progress.

## Language

The product targets Spanish-speaking users primarily. UI copy, bot responses, and documentation (GUIA_DESARROLLO.md) are in Spanish. Code comments and variable names are in English.
